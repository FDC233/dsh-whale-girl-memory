# 经验库 experience/

这里是**鲸鱼娘记忆星港**的正式经验库——所有 `.json` 文件都是**已经过维护者审核**的 dsh-memory 格式经验（[规范见 docs/FORMAT.md](../docs/FORMAT.md)）。

## 如何投稿

1. 打开[记忆星港分享站](https://fdc233.github.io/dsh-whale-girl-memory/)，切到「投稿流」标签；
2. 填写标题与经验内容（可插入经验 JSON 模板）；
3. 点「在 GitHub 提交投稿」——会在 GitHub 官网打开一个**预填好的 Issue 创建页**；
4. 用你自己的 GitHub 账号登录提交（由 GitHub 承担登录、2FA、验证码、限流等反滥用防护）；
5. 维护者审核后会把经验合并进本目录，并在 Issue 中回复。

## 审核标准

- 格式符合 [dsh-memory 格式 v1](../docs/FORMAT.md)（type / title / content 必填）
- 内容为通用、可复用的经验（用户习惯、流程技巧、经验教训、工具用法等）
- 不含密钥、隐私、违法违规或攻击性内容
- 内容质量由维护者判断，不保证全部采纳

## 文件命名

`<type>-<简短描述>.json`，例如 `preference-tsundere-cn.json`。
